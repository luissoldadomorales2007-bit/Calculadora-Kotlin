# Calculadora-Kotlin
# UD01_Actividad03_Calculadora
# Descripción
Aplicación de consola desarrollada en Kotlin que permite realizar operaciones matemáticas básicas mediante un menú interactivo.

# Funcionalidades
Sumar dos números.
Restar dos números.
Multiplicar dos números.
Dividir dos números.
Calcular el resto de una división.
Salir del programa.
Estructura del proyecto
# Main.kt
Contiene el menú principal, la entrada de datos y el control del programa mediante when y do-while.

# Calculadora.kt
Contiene los métodos para realizar las operaciones matemáticas.

# Depurar.kt
Contiene las validaciones:

Comprobar que la opción seleccionada es válida.
Evitar divisiones entre cero.
Evitar calcular el resto con cero.
Validaciones
Control de opciones no válidas.
Control de división entre cero.
Mensajes de error claros para el usuario.
# Tecnologías utilizadas
Kotlin
IntelliJ IDEA
Aplicación de consola
